# Neural Odyssey — Vertical Slice 01

A zero-dependency browser prototype for the visual direction and scene-flow concept.

## Run
Open index.html in a modern browser, or serve the repository root with any static HTTP server and visit /demo/neural-odyssey/.

## Controls
Select Genesis, Convergence or Emergence; play/pause the sequence; scrub the timeline.

## Scientific status
All nodes and links are deterministic synthetic illustration. This is not a neural simulation, connectome, anatomical reconstruction or measured dataset.

## Scope
Tests composition, restrained motion, chapter transitions, typography and the future scene-to-render workflow. It does not include 3D rendering, voiceover, final soundtrack or scientific validation.
