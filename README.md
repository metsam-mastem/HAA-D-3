## Mission

Build a traceable living knowledge base and an evidence-led engineering plan to investigate hybrid neural architectures: spatially embedded neural graphs, modular computation, recurrent and multi-path feedback, foundation-model integration, local learning, resource-aware execution, and scientific visualization.

This repository currently documents the research and planning baseline. It does **not** claim a validated novel neural architecture, measured performance gain, or completed vertical slice.

## Current research position

- Spatial embedding is a studied research direction; placing neurons in 3D is not by itself evidence of improved intelligence.
- Feedback mechanisms require objectives, stability controls, and ablation benchmarks.
- A pretrained foundation model is the pragmatic “brain-first” baseline; a custom spatial/feedback network should initially act as a bounded, testable subsystem or adapter.
- Dense neural connectivity can be resource-expensive. Sparse topology, low-rank methods, quantization, selective execution, and profiling are candidate interventions, not promised gains.
- Vertical slice should prove a small end-to-end workflow before expanding scope.

## Initial success criteria

1. Every major claim is linked to evidence or marked as a hypothesis.
2. Research branches have explicit scope, dependencies, and outputs.
3. Architecture modules have stable contracts and acceptance tests.
4. A reproducible vertical slice has baseline comparisons and resource measurements.
5. Creative visualizations remain faithful to their scientific source and distinguish metaphor from measurement.
6. Rights, licenses, provenance, and data privacy are documented.

## Work status

This is the first documentation baseline. Research, code execution, benchmarks, and cinematic production are not yet complete. Statuses must be reported as **PASS / FAIL / NOT RUN / BLOCKED** with evidence.
