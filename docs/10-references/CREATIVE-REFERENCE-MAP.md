## Scientifically grounded cinema case: Interstellar / black-hole visualization
- Primary paper: James et al., “Gravitational lensing by spinning black holes in astrophysics, and in the movie Interstellar,” Classical and Quantum Gravity 32 (2015), DOI https://doi.org/10.1088/0264-9381/32/6/065001
- Caltech author archive: https://authors.library.caltech.edu/records/njdcq-95891
- NASA visualization and explanation: https://science.nasa.gov/universe/black-holes/new-nasa-black-hole-visualization-takes-viewers-beyond-the-brink/
- NASA behind-the-scenes: https://svs.gsfc.nasa.gov/14818/
- Event Horizon Telescope realism note: https://eventhorizontelescope.org/faq/how-realistic-are-movie-depictions-black-holes-eg-interstellar

**Method lesson:** scientific equations/model → renderer → artistic decisions → audience-facing image. Record which effects are physically derived and which are adjusted for readability/drama. A compelling image is not itself proof.
