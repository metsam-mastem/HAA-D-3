# Roadmap and Evidence Gates

## Phase 0 — Repository truth and governance
Reconcile README links with existing files; establish document ownership, versioning, ADRs and issue templates; define claim classes and provenance. Gate: every advertised document exists or is marked planned.

## Phase 1 — Vertical Slice 01: Neural Emergence
Build a deterministic synthetic scene; validate timeline controls and accessibility; review visual identity and narrative. Gate: acceptance checklist is reviewed and no scientific claim is implied.

## Phase 2 — Scientific data binding
Select one bounded research question and a permissively licensed dataset or formal model. Define schema, units, provenance and baseline. Bind validated outputs to SceneSpec. Gate: independent reproduction or analytical validation.

## Phase 3 — Production pipeline
Add Blender adapter and render manifest; shot timeline, camera and lighting presets; original audio design and stem workflow. Gate: reproducible render and QC report.

## Phase 4 — Research workbench
Add source registry, claim ledger, experiment registry and artifact browser. Add simulator adapters only when justified. Gate: traceability from source to released shot.

## Phase 5 — Productization
Add user workflows, permissions, export profiles, documentation, performance budgets and release process. Gate: usability, reliability, licensing and operational review.

Do not advance a phase because a calendar date has arrived. Advance only when its evidence gate is satisfied.
