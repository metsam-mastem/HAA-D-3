# Research Plan & Evidence Method

## Research questions
RQ1: Which spatial representation of units/modules is meaningful and measurable?
RQ2: Which feedback/learning methods can combine without incompatible objectives or unstable dynamics?
RQ3: How should a pretrained foundation model interface with custom spatial modules?
RQ4: Does modularization or conditional execution improve task quality/cost against baseline?
RQ5: What representations make system inspectable and reproducible?
RQ6: What is the smallest end-to-end slice proving the research workflow?

## Streams
Math foundations; neural families; spatial graph/3D; feedback and stability; foundation model adapters; systems/software; hardware/resource efficiency; knowledge graph; scientific visualization; animation/music/cinema; evaluation/licensing/safety.

## Source tiers
A: peer-reviewed papers, standards, official docs, primary repo code/license.
B: technical reports, maintainer notes, preprints (clearly labeled).
C: tutorials/videos/community (discovery leads, not primary proof).
Creative references: film/design/music as inspiration, not scientific evidence.

## Method
Question → foundational terms → survey/primary work → inspect methods, outcomes, limitations → citation chaining → repository/license review → contradiction and gap synthesis.

## Evidence record
ID; claim; URI; author/date; source type; section/figure/code location; result; method; context; limitation; confidence; related concepts; status (SUPPORTED, CONTRADICTED, MIXED, UNVERIFIED).

## Hypothesis record
ID; rationale; null; measurable variables; task; baseline; design; falsifier; compute budget; result; decision.

## Status labels
CONFIRMED (verified direct support); SOURCE-CLAIM; INFERRED; HYPOTHESIS; MIXED; UNKNOWN; REJECTED; NOT RUN.

## Integrity
Never invent citations/results. README benchmark assertions are source-claims until reproduced. Report negative results. Separate observation from model interpretation and correlation from causation. Record versions/access dates. Technical value and license permission are separate.

## Milestones
M1 taxonomy/source registry; M2 foundations (seRNN, feedback alignment, GLE, graph/SNN/transformers); M3 alternatives and novelty gap; M4 ES/testability; M5 benchmark plan; M6 evaluated report.
