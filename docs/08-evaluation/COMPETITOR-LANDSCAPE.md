# Competitor & Research Landscape
**Status:** preliminary taxonomy; not complete market analysis.

## Categories
Foundation model ecosystems; local inference and serving; graph/neural research frameworks; SNN simulation; agent/workflow orchestration; knowledge graph/research systems; scientific visualization and animation; local-first dev workbenches.

| Category | Examples | Strength | Relationship |
|---|---|---|---|
| Foundation models | HF Transformers, open-weight families | pretrained broad capability | baseline brain/adapters |
| Local inference | llama.cpp, Ollama ecosystem | local model execution/quantization | backend option |
| Serving | vLLM | throughput serving | later deployment |
| Graph ML | PyTorch Geometric, DGL | graph learning | experimental substrate |
| SNN | Norse, snnTorch, Brian2 | spike models/simulation | research branch |
| Neural/cognitive simulation | Nengo | model simulation | reference |
| Knowledge graph | user repo SSG, graph libs | canonical graph and projection | reuse patterns after audit |
| Multimodal workbench | VINT Reel Intelligence | media evidence/provenance | workflow patterns |
| Agent orchestration | LangGraph etc. | stateful workflows | defer until need |
| 3D creative | Blender, Houdini, Unreal, Three.js | rendering and motion | creative tools, not neural engines |

## Differentiation hypothesis
Not “3D neurons” alone: a traceable research→engineering→visual storytelling workbench linking evidence, formalization, contracts, tests, resource profiles, and scientific visualizations.

## Candidate value
Evidence-linked decisions; interchangeable model/custom adapters; inspectable spatial graph and feedback config; controlled ablation ledger; resource-quality tradeoff; typed-data visualization; serialized research presentation.

## Competitive risk
Established tools may outperform bespoke work on training, serving, reliability and ecosystem. Integrate instead of reinventing.

## Fair comparison
Fix task, dataset/split, model version, compute, config and metric. Compare baseline, candidate and ablations. Report quality, latency, memory, complexity, reproducibility and license. Superiority not asserted without results.
